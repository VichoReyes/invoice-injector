# 🧾 Prueba Técnica - Inyección de Facturas al ERP

## 🚀 ¿Cómo ejecutar?

**Clona el repositorio**

```bash
git clone https://github.com/VichoReyes/recruiting-frontend-test.git
cd recruiting-frontend-test
```

Instala las dependencias

```bash
npm install
```

Levanta el entorno de desarrollo

crea tu variable de entorno token en `.env`:

```
VITE_AUTH_TOKEN="blabla-blabla"
```

Y ejecuta el proyecto

```bash
npm run dev
```

Esto abrirá la aplicación en http://localhost:5173

Por favor prueben la aplicación en **modo claro**.
